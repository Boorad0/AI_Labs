**Ответ** (7.1 с):

Хэширование — это односторонний процесс преобразования данных в фиксированный набор символов, который невозможно восстановить обратно к исходному тексту. Шифрование же представляет собой двусторонний процесс, где информация кодируется с помощью ключа и может быть расшифрована для чтения другими людьми. Главная цель хэширования — обеспечить целостность данных и проверку их подлинности, а не сохранение конфиденциальности. В отличие от шифрования, хэш-функции не используют ключи, поэтому только владелец исходных данных может вычислить их хэш. Таким образом, хэширование подходит для хранения паролей и проверки файлов, тогда как шифрование необходимо для защиты передаваемой или хранимой приватной информации.

## Запрос 5 (код)

Напиши функцию Python, проверяющую, содержит ли строка IPv4-адрес.

**Ответ** (19.5 с):

Вот функция на Python, которая проверяет, содержит ли строка валидный IPv4-адрес. Она использует регулярное выражение для проверки формата и разбивает строку на слова для поиска совпадений.

```python
import re

def contains_ipv4_address(text: str) -> bool:
    """
    Проверяет, содержит ли строка валидный IPv4-адрес.
    
    Аргументы:
        text (str): Строка для проверки.
    
    Возвращает:
        bool: True, если найден валидный IPv4-адрес, иначе False.
    """
    # Регулярное выражение для валидации IPv4
    # Формат: X.X.X.X, где X — число от 0 до 255
    ipv4_pattern = r'\b(?:(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\.){3}(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\b'
    
    # Ищем совпадения в строке
    return bool(re.search(ipv4_pattern, text))

# Примеры использования
if __name__ == "__main__":
    test_cases = [
        "Связаться с нами по адресу 192.168.1.1",
        "Пожалуйста, настройте 10.0.0.1 на роутере",
        "Это просто текст без адресов",
        "192.168.1.1",
        "256.100.100.100",  # Неверный адрес (256 > 255)
        "192.168.1.256",   # Неверный адрес
        "Привет, 1.2.3.4, как дела?",
    ]
    
    for test in test_cases:
        result = contains_ipv4_address(test)
        print(f"Строка: '{test}' -> Содержит IPv4: {result}")
```

### Как это работает:
1.  **Регулярное выражение (`ipv4_pattern`)**:
    *   `\b` — гарантирует, что адрес находится на границе слова (чтобы не совпадать с частью другого слова, например, `192.168.1.1abc`).
    *   `(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)` — эта часть строго проверяет диапазон от 0 до 255 для каждой октеты:
        *   `25[0-5]` (250–255)
        *   `2[0-4]\d` (200–249)
        *   `1\d\d` (100–199)
        *   `[1-9]?\d` (0–99)
    *   `\.` — разделяет октеты точкой.
    *   Повторение `{3}` для первых трех октетов и один раз для последнего.
2.  **`re.search`**: Находит первое совпадение в строке. Если совпадение найдено, функция возвращает `True`.

Этот подход надежен и корректно обрабатывает как целые строки, содержащие только IP, так и тексты, где IP является частью предложения.

## Запрос 5 (код)

Напиши функцию Python, проверяющую, содержит ли строка IPv4-адрес.

**Ответ** (25.2 с):

Для решения этой задачи лучше всего использовать встроенную библиотеку `ipaddress`, так как она корректно обрабатывает все нюансы (например, разные форматы записи или пустые строки).

Ниже представлены два способа: «правильный» (через библиотеку) и «быстрый» (через регулярные выражения).

### Способ 1: Использование библиотеки `ipaddress` (Рекомендуемый)
Этот метод самый надежный, так как он проверяет валидность адреса (например, он не пропустит `999.999.999.999`).

```python
import ipaddress

def contains_ipv4(text: str) -> bool:
    # Разбиваем текст на слова, чтобы найти адрес среди других символов
    words = text.split()
    for word in words:
        # Очищаем слово от возможных знаков препинания (точки, запятые)
        clean_word = word.strip('.,!?;:')
        try:
            ipaddress.IPv4Address(clean_word)
            return True
        except ValueError:
            continue
    return False

# Примеры:
print(contains_ipv4("Мой IP: 192.168.1.1"))      # True
print(contains_ipv4("Свяжись по адресу 10.0.0.255")) # True
print(contains_ipv4("Это просто текст"))          # False
print(contains_ipv4("Неверный адрес 256.0.0.1"))  # False
```

---

### Способ 2: Использование регулярных выражений (Regex)
Этот метод работает быстрее, если вам нужно просто найти последовательность цифр в формате IP, не проверяя их строго на валидность (например, если вам достаточно найти `1.2.3.4`).

```python
import re

def contains_ipv4_regex(text: str) -> bool:
    # Регулярное выражение для поиска IPv4
    ipv4_pattern = r'\b(?:(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.){3}(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\b'
    return bool(re.search(ipv4_pattern, text))

# Примеры:
print(contains_ipv4_regex("IP адрес 172.16.254.1")) # True
print(contains_ipv4_regex("Тут нет адреса"))         # False
```

### Какой выбрать?
1.  **Способ 1 (`ipaddress`)** — используйте, если вам важна **точность**. Он гарантирует, что найденная строка является настоящим IP-адресом.
2.  **Способ 2 (Regex)** — используйте, если вам нужно **быстро просканировать огромный объем текста** и вам достаточно простого визуального соответствия формату.

**Важное примечание:** Если вам нужно найти IP внутри строки, где он может быть склеен с другими символами (например, `http://192.168.1.1/index.html`), лучше использовать регулярное выражение, так как `split()` в первом способе может не сработать.
